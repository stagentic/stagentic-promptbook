# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) documenting significant technical decisions made in this project.

## What is an ADR?

An ADR captures an important architectural decision along with its context, consequences, and alternatives considered. See [template.md](template.md) for the standard format.
